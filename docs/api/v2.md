# API V2

Source: `routes/api.php` `prefix('v2')`.

## Investor (`/api/v2/investor`)

### Auth

- Register: `send-otp` → `verify-otp` → `complete` (manual or Google)
- `debug-google-token` (debug — treat carefully in production)
- Login: `login` (mobile+MPIN), `login-google`
- Forgot: send/resend/verify OTP + change-password

## Seller (`/api/v2/seller`)

Auth actor: `SellerMasterModel` (`seller_master` table) via `seller-api-guard`.

Login credentials live on `seller_master` (`mobile_number`, `password`, etc.) — set from Admin seller create/edit.

Profile/login payload includes feature access flags (same names as investor): `is_primary_access`, `is_secondary_access`, `is_preipo_access`.

**Seller dashboard** (`GET /api/v2/seller/dashboard`):

- `summary.transactions`: `pending` / `processing` / `completed` (same buckets as seller Pre-IPO list; scoped to `seller_id`)
- `summary.deals`: `available` (status available and not expired) / `expired` (own deals only)
- `summary.companies`: `pending_approval` (own submissions), `total_companies` (approved catalog), `price_uploaded_today` / `price_not_uploaded_today` (this seller’s quotes today vs catalog)
- `charts`: monthly/quarterly completed volume, transaction status donut, deals available/expired, top companies by completed amount
- `recent`: latest 5 transactions, deals, my_submissions (no enquiries)

| `GET /api/v2/seller/company/detail` | `headtoken` + Bearer | Approved catalog detail, or seller’s own non-rejected submission. Includes `promoters` + `share_holders` + `seller_share_prices` (today’s quotes, `sell_price` ascending, nested `seller`). |
| `GET /api/v2/seller/company/my-submissions` | `headtoken` + Bearer | Seller’s own submissions (pending/approved/rejected). Filters: `type`, `approval_status`, `skip`, `take`. |
| `POST /api/v2/seller/company/promoters` | `headtoken` + Bearer | Replace-all promoters for `company_id`. Each: `name`, `designation`, `experience` required; `url` optional. Read via detail. |
| `POST /api/v2/seller/company/shareholders` | `headtoken` + Bearer | Replace-all shareholders for `company_id`. Body is year-grouped (same shape as detail `share_holders`): each group has `year` + `shareholders[]` of `name` + `percentage`. Same person across years is stored as one holder. Read via detail. |
| `POST /api/v2/seller/company/update-share-price` | `headtoken` + Bearer | Batch seller quote update for multiple approved companies. Appends history to `seller_company_share_price`; sets `company.is_price_updated_today=1` per company. Does **not** change admin market prices. |
| `GET /api/v2/seller/company/deals/list` | `headtoken` + Bearer | List **only the authenticated seller’s** deals (`created_by_seller_id`). Approved unlisted/secondary companies. Each deal includes `deal_type`, `is_mine`, `is_hot_deal`, `expired_at` (datetime), `is_expired`, + `company` (`id`, `brand_name`, `slug`, `logo`, `type`). |
| `POST /api/v2/seller/company/deals/create` | `headtoken` + Bearer | Create **buy or sell** deal on any approved unlisted/secondary company. Stamps `created_by_seller_id`. See body below. |
| `POST /api/v2/seller/company/deals/update` | `headtoken` + Bearer | Update **own** deal by `uuid` (including `deal_type`). See body below. |
| `POST /api/v2/seller/company/deals/delete` | `headtoken` + Bearer | Soft-delete **own** deal by `uuid` (`is_deleted=1`). See body below. |
| `GET /api/v2/seller/sell-enquiries/list` | `headtoken` + Bearer | List **all** partner **sell** enquiries (`enquiry_type=sell`). Soft-deleted excluded. Optional `status`, `company_id`, `skip`, `take`. |

**Seller shareholders — body:**
```
{
  "company_id": 12, // integer required — seller-owned company
  "shareholders": [ // array optional — omit or [] clears all
    {
      "year": "2025", // string required — max 20
      "shareholders": [ // array optional
        { "name": "Shareholder 1", "percentage": 40.5 }, // name required; percentage 0–100
        { "name": "Shareholder 2", "percentage": 25 }
      ]
    },
    {
      "year": "2024",
      "shareholders": [
        { "name": "Shareholder 1", "percentage": 38 },
        { "name": "Shareholder 2", "percentage": 22 }
      ]
    }
  ]
}
```
Storage is unchanged: unique names on `company_share_holder`, year/% on `company_share_holder_percentage`. Duplicate names in the same year last-write-wins.

**Seller update share price — body:**
```
{
  "prices": [ // array required — min 1; each item = one company quote
    {
      "company_id": 12, // integer required — approved company; distinct within request
      "sell_price": 100.5, // numeric required — min 0
      "buy_price": 98, // numeric optional — min 0
      "min_qty": 10, // integer required — min 1
      "total_qty": 500 // integer optional — min 1; if set must be >= min_qty
    },
    {
      "company_id": 15, // integer required
      "sell_price": 55, // numeric required
      "min_qty": 5 // integer required
    }
  ]
}
```
All-or-nothing: invalid row rejects the whole request. Each success appends a `seller_company_share_price` history row (`seller_id` from auth, `date` = today) and sets `company.is_price_updated_today=1` for those companies. Daily reset via `app:company-share-price-update-today-change` (also clears admin `price_updated_today`).

**Seller update share price — success response:**
```
{
  "status": 1,
  "message": "Share prices updated",
  "data": {
    "updated_count": 2, // integer
    "company_ids": [12, 15] // integer[] — companies updated in this request
  }
}
```

**Seller deals — list query:**
```
GET /api/v2/seller/company/deals/list?company_id=12&type=unlisted&skip=0&take=15
```
- `company_id` — integer optional — filter to one approved unlisted or secondary company
- `type` — string optional — `All` \| `unlisted` \| `secondary` — default `All` (both)
- `skip` — integer optional — default 0
- `take` — integer optional — default app pagination limit

**Seller deals — create body:**
```
{
  "company_id": 12, // integer required — approved unlisted or secondary
  "deal_type": "sell", // string required — buy | sell
  "available_quantity": 1000, // integer optional — min 0; omit = 0 on create
  "share_price": 250.50, // numeric required — min 0 — this deal's price
  "minimum_qty": 10, // integer required — min 1
  "status": "available", // string optional — available | half_sold | sold — default available
  "is_hot_deal": false, // boolean optional — default false
  "expired_at": "2026-12-31 23:59:59" // datetime optional — format Y-m-d H:i:s — null = no expiry
}
```
`processing_fee_percentage` is set by backend to `0` (not accepted from client). Create a separate deal row for buy and for sell (two creates).

**Seller Pre-IPO transactions** (scoped to `pre_ipo_transaction.seller_id` = authenticated seller; outside `company` routes):

| Method | Path | Auth |
|--------|------|------|
| GET | `/api/v2/seller/pre-ipo/transaction` | `headtoken` + Bearer |
| GET | `/api/v2/seller/pre-ipo/transaction/detail` | `headtoken` + Bearer |

**List query params:**
- `status` — optional — `pending` \| `processing` \| `completed`
  - `pending` = admin market: `created_by IS NULL` AND `status = 0`
  - `processing` = admin pending: `status > 1` AND `status != 5`
  - `completed` = admin completed: `status = 5`
- `company_id` — optional — exact company id
- `company` — optional — partial match on company `brand_name`
- `skip` / `take` — optional pagination (default take = `app_pagination_limit`)

Each list/detail row includes `status_list` from `PreIpoTransactionHelper::getStatusListForApplicationV2`. Detail requires `transaction_id` and returns only the calling seller’s transaction.

**Seller sell-enquiries** (outside `company` routes; `enquiry_type` fixed to `sell`; returns **all** sell enquiries for any authenticated seller):

| Method | Path | Auth |
|--------|------|------|
| GET | `/api/v2/seller/sell-enquiries/list` | `headtoken` + Bearer |

**List query params:**
- `status` — optional — `pending` \| `completed`
- `company_id` — optional — exact company id
- `skip` / `take` — optional pagination (default take = `app_pagination_limit`)

**Response:** `data[]` with `uuid`, `enquiry_type`, `status`, `quantity`, `offer_price`, `offer_valid_till`, `notes`, `created_at`, nested `company` (`id`, `brand_name`, `slug`, `logo`, `type`), optional `deal` (`id`, `uuid`, `deal_type`, `share_price`, `available_quantity`, `minimum_qty`), and `partner` (`id`, `name`). Also returns `total`, `skip`, `take`.

Investor/business company list/home/detail paths only return `approval_status=approved` companies.
